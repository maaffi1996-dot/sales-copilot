# دستیار فروش هوشمند — پروژه Next.js + FastAPI

این پروژه، نسخه‌ی کدشده‌ی پروتوتایپ HTML قبلی است؛ همان طراحی بنفش/یاسی و همان دو
صفحه (لندینگ عمومی با دموی آپلود، و داشبورد داخلی)، اما این‌بار به‌عنوان یک اپلیکیشن
واقعی و قابل‌توسعه.

## ساختار پروژه

```
sales-copilot/
├── frontend/     Next.js 14 (App Router) + TypeScript + Tailwind CSS
│   ├── app/
│   │   ├── page.tsx              صفحه لندینگ (هیرو، دموی تعاملی، ویژگی‌ها، قیمت‌گذاری)
│   │   └── dashboard/page.tsx    داشبورد داخلی (بعد از ورود)
│   ├── components/                کامپوننت‌های لندینگ
│   └── components/dashboard/      کامپوننت‌های داشبورد
│
└── backend/      FastAPI + Pandas + Anthropic SDK
    ├── main.py                    اندپوینت‌های /api/analyze و /api/ask
    └── app/
        ├── analysis.py            پردازش اکسل/CSV با Pandas (منطقی که قبلاً در جاوااسکریپت بود)
        └── ai.py                  لایه انتزاعی فراخوانی مدل هوش مصنوعی
```

## چرا این جدا شد (فرانت/بک)

در پروتوتایپ HTML قبلی، خواندن اکسل و فراخوانی مدل هوش مصنوعی همه در مرورگر کاربر
انجام می‌شد. این برای یک دمو خوب بود، اما برای داده واقعی مشتریان دو مشکل دارد:
پردازش فایل‌های بزرگ در مرورگر کند/ناپایدار است، و کلید API مدل نباید در کد سمت
کلاینت افشا شود. به همین دلیل الان:

- **فرانت‌اند (Next.js)** فقط رابط کاربری و ارسال/دریافت درخواست است.
- **بک‌اند (FastAPI)** فایل را می‌خواند، با Pandas پردازش می‌کند، و کلید API مدل را
  فقط سمت سرور (در `.env`) نگه می‌دارد.

## راه‌اندازی بک‌اند

```bash
cd backend
python -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# مقدار ANTHROPIC_API_KEY را در فایل .env با کلید واقعی خودت جایگزین کن

uvicorn main:app --reload --port 8000
```

بک‌اند روی `http://localhost:8000` بالا می‌آید. تست سریع:
`curl http://localhost:8000/api/health`

## راه‌اندازی فرانت‌اند

```bash
cd frontend
npm install

cp .env.local.example .env.local
# در صورت نیاز آدرس بک‌اند را تغییر بده

npm run dev
```

فرانت‌اند روی `http://localhost:3000` بالا می‌آید:
- `/` صفحه لندینگ با دموی تعاملی آپلود فایل
- `/dashboard` داشبورد داخلی نمونه

## نکات مهم قبل از استفاده واقعی (چک‌لیست فاز بعد)

این نسخه هنوز MVP آموزشی/دمو است، نه محصول تولیدی کامل. قبل از دادن آن به مشتری
واقعی حتماً این‌ها را اضافه کن:

- **احراز هویت واقعی** — الان هیچ لاگین/session‌ای پیاده نشده؛ صفحه داشبورد برای
  هرکسی که لینک را دارد باز می‌شود.
- **پایگاه داده** — نتایج آپلودها الان ذخیره نمی‌شوند؛ برای تاریخچه و مقایسه ماه به
  ماه به PostgreSQL نیاز داری.
- **مدل هوش مصنوعی جایگزین برای دسترسی از ایران** — به‌دلیل تحریم‌ها دسترسی مستقیم
  به API آنتروپیک از ایران محدود است؛ فایل `backend/app/ai.py` عمداً به‌شکل یک لایه
  جدا نوشته شده تا بعداً به‌جای Anthropic بتوانی یک مدل متن‌باز خودمیزبان (Llama،
  Qwen, DeepSeek) یا یک پروکسی را جایگزین کنی، بدون تغییر در بقیه‌ی کد.
- **اعتبارسنجی و امنیت آپلود** — محدودیت حجم فایل، پاکسازی محتوای مخرب، و نرخ‌محدودسازی
  درخواست‌ها (rate limiting) روی `/api/analyze` و `/api/ask`.
